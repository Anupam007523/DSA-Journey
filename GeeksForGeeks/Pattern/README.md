# Hollow Square Pattern

## Platform
GeeksforGeeks

## Difficulty
Basic

## Topic
Patterns, Nested Loops

## Problem Link
https://www.geeksforgeeks.org/problems/hollow-square-pattern/

## Approach
Used two nested `for` loops to traverse the rows and columns of the square. Printed `'*'` whenever the current position was on the boundary (first row, last row, first column, or last column). For all other positions, printed spaces to create the hollow portion of the square.

## Time Complexity
O(n²)

## Space Complexity
O(1)

> **Alternative:** The same pattern can also be generated by building each row in a `StringBuilder` and printing it at once. However, directly printing inside nested loops is simpler and commonly used for pattern-printing problems.

## Key Learning
- Practiced using nested `for` loops for pattern printing.
- Learned how to identify boundary elements using row and column indices.
- Understood how conditional statements can be used to differentiate border and inner cells.
- Improved understanding of coordinate-based pattern generation.
