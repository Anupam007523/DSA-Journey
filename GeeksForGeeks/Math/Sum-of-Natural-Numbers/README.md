# Sum of Natural Numbers

## Platform
GeeksforGeeks

## Difficulty
Easy

## Topic
Mathematics, Basic Programming

## Problem Link
https://www.geeksforgeeks.org/problems/sum-of-natural-numbers/1

## Approach
Used the mathematical formula `n × (n + 1) / 2` to calculate the sum of the first `n` natural numbers in constant time. If the input number is less than or equal to `0`, returned `0` since there are no positive natural numbers to sum.

## Time Complexity
O(1)

## Space Complexity
O(1)

## Key Learning
- Learned how to use the formula for the sum of the first `n` natural numbers.
- Understood how to handle edge cases when `n` is less than or equal to `0`.
- Practiced solving a problem using mathematical optimization instead of loops.
