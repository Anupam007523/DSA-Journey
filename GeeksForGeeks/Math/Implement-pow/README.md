# Implement Pow

## Platform
GeeksforGeeks

## Difficulty
Medium

## Topic
Mathematics

## Problem Link
https://www.geeksforgeeks.org/problems/power-of-numbers-1587115620/1

## Approach
Used Java's built-in `Math.pow()` method to calculate the value of the base raised to the given exponent. The method directly returns the result as a `double`, making the implementation concise and efficient.

## Time Complexity
O(1)

## Space Complexity
O(1)

> **Alternative:** This problem can also be solved manually using **Binary Exponentiation (Fast Power)**, which computes the result in **O(log e)** time without relying on the built-in `Math.pow()` function. This approach is commonly asked in coding interviews.

## Key Learning
- Learned how to use Java's `Math.pow(base, exponent)` method.
- Understood that `Math.pow()` returns a `double`.
- Practiced solving exponentiation problems using built-in library functions.
- Learned that Binary Exponentiation is a more common algorithmic solution when implementing the power function from scratch.
