# Shuffle the Array

## Platform
LeetCode

## Difficulty
Easy

## Topic
Arrays

## Problem Link
https://leetcode.com/problems/shuffle-the-array/

## Approach
Created a new array to store the shuffled result. Iterated through the first half of the input array while simultaneously picking corresponding elements from the second half and placing them alternately in the new array.

## Time Complexity
O(n)

## Space Complexity
O(n)

## Key Learning
- Learned how to merge two halves of an array alternately.
- Practiced index manipulation using a temporary array.
- Understood how to work with multiple pointers within a single loop.
