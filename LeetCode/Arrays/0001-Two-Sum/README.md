# Two Sum

## Platform
LeetCode

## Difficulty
Easy

## Topic
Arrays, HashMap

## Problem Link
https://leetcode.com/problems/two-sum/

## Approach
Used a brute-force approach by checking every pair of elements using nested loops. If the sum of two elements equals the target, return their indices.

## Time Complexity
O(n²)

## Space Complexity
O(1)

## Key Learning
- Learned how to iterate through all possible pairs.
- This is a simple solution before optimizing with HashMap.
